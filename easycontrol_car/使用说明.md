# 领克投屏 使用说明

> 适用 App：领克投屏（车机端）
> 包名：top.eiyooooo.easycontrol.app
> 版本：2.0.0
> 适配车型：领克 09（2022 款），OSN2.0 安卓 9 车机（高通 8155）

---

## 一、这是什么 / 能干什么

「领克投屏」是专为领克 09 车机大屏深度定制的投屏 App。它把你的安卓手机画面**无线投射**到车机中控屏上，自动以**全屏横屏**显示，并且：

- **手机不需要装任何 App**：车机端 App 会通过内置 ADB 自动把服务端程序推到手机上运行。
- **息屏也能继续投屏**：连接成功后手机屏幕自动关闭（只关背光、不锁屏），省电又不影响画面，车机大屏上一切照常。
- **蓝牙手柄打游戏**：手机蓝牙配对手柄后，直接在大屏上玩游戏；车机屏幕也能用手指点，相当于模拟手机触摸。
- **沉浸式全屏**：连接后自动隐藏车机系统状态栏和导航栏，画面铺满整个大屏。

本方案不走系统录屏（MediaProjection）通道，因此**正常不会因为手机息屏而中断投屏**。

## 二、手机端准备（只做一次）

手机是安卓 11 及以上（你的手机是安卓 17），全程无线即可，**不需要 USB 线**。

### 1. 打开「开发者选项」
1. 打开手机「设置」→「关于手机」。
2. 找到「版本号」一栏，**连续快速点击 7 次**。
3. 提示「您已处于开发者模式」即成功，回到设置主菜单，会多出一个「开发者选项」入口。

### 2. 开启 USB 调试
1. 进入「开发者选项」。
2. 打开「USB 调试」开关。
3. 首次连接时手机会弹出「是否允许 USB 调试」授权框，**务必勾选「一律允许使用这台设备进行调试」**，再点确定。

### 3. 开启「无线调试」（关键）
1. 仍在「开发者选项」里，找到并打开「无线调试」。
2. 点进「无线调试」页面，你会看到两组信息：
   - **IP 地址和端口**，形如 `192.168.x.x:xxxxx`（这是待会儿要填到车机里的地址）。
   - 点「使用配对码配对设备」后会弹出**配对码**和一组单独的配对地址、配对端口。
3. **记住：配对码弹窗要一直保持在屏幕上**，直到车机端配对完成。配对码有时效，关掉弹窗再回来就会刷新成新的。

### 4. 配对手柄（可选，但玩游戏必做）
1. 手机「设置」→「蓝牙」，打开蓝牙。
2. 把手柄调到配对模式（一般是长按 Home 或专属配对键，指示灯快闪）。
3. 在手机蓝牙列表里点选手柄完成配对。
4. 配对成功后，进入游戏即可直接用手柄操作，无需在 App 里再设置。

## 三、车机端安装与首次设置

### 1. 安装 APK
把 `领克投屏.apk` 装到车机上，任选一种方式：
- 用车机自带浏览器下载后点击安装；
- 或通过「甲壳虫 ADB 助手」等车机端工具推送安装。

> 领克 09 OSN2.0 允许安装第三方 APK，安装时如提示「未知来源」，按提示允许即可。

### 2. 首次打开，授权两个权限
装好后第一次打开 App，建议在 App 内的「设置」里完成：
- **悬浮窗 / 显示在其他应用上层**：安卓 9 上叫「显示在其他应用上层」，必须给，否则全屏时悬浮按钮条弹不出来。
- **使用情况访问权限**：可选，建议一并授权，便于 App 正确识别前台应用。

### 3. 添加设备
1. 回到 App 主界面，点「添加设备」。
2. 设备地址填**手机无线调试页上显示的「IP 地址和端口」**（注意：是无线调试主页那一组，不是配对弹窗里的那一组）。
3. 保存。

### 4. 第一次配对（仅安卓 11+ 需要做一次）
1. 手机端停在「无线调试」→「使用配对码配对设备」弹窗上，看清配对码。
2. 车机端 App 点「配对」按钮。
3. 输入手机上显示的**配对码**，确认。
4. 提示配对成功后，手机端弹窗可以关掉。

### 5. 连接
1. 回到 App 主界面，点刚才保存的那台设备。
2. 此时手机屏幕会弹出「允许 USB 调试吗？」授权框，**勾选「一律允许」**并确定。
3. 之后车机会用保存好的 ADB 密钥自动认证，**以后连接不再需要重复授权**。

> 小提示：手机和车机要在同一个网络下。最简单的做法是手机连车机热点，或手机、车机都连同一个 WiFi。

## 四、投屏全屏怎么用

连接成功后，App 会自动：
- 切到**全屏横屏**，画面铺满中控大屏；
- **隐藏车机系统状态栏和导航栏**（沉浸式）；
- **自动关闭手机屏幕**（息屏省电，投屏不断流）。

### 悬浮按钮条
在全屏画面上，**点一下屏幕边缘**，会从边缘滑出一排悬浮按钮，约 2 秒后自动隐藏。按钮从左到右大致是：

| 按钮 | 作用 |
| --- | --- |
| 旋转屏幕 | 切换横屏 / 竖屏方向 |
| 返回键 | 相当于手机的返回 |
| Home 键 | 回到手机桌面 |
| 最近任务 | 查看手机后台 App |
| 灯泡 | **点亮 / 熄灭手机屏幕**（息屏后想看手机屏就点它） |
| 电源键 | 相当于手机电源键 |
| 退出 | 断开投屏，回到车机 App 主界面 |

车机屏幕可以直接用手指点，点到哪里就相当于在手机上点哪里。

### 息屏投屏
- 连接成功后手机自动息屏，**车机画面不会断**，放心玩。
- 如果想看一眼手机屏幕（比如扫码、回消息），点悬浮条上的**灯泡**按钮，手机屏会亮起来；再点一次又会息屏。

### 断开连接
点悬浮条上的「退出」，或直接按车机 Home 键回到桌面，即断开投屏。下次在 App 主界面再点一次设备即可重连。

## 五、常见问题与排查

### 1. 点了连接没反应 / 设备显示 offline
- 先到手机「开发者选项」里**关掉再重新打开「无线调试」**，让 IP 和端口刷新一次。
- 回到车机 App，把旧设备删掉，重新「添加设备」，填最新的 IP:端口。
- 确认手机和车机在**同一个 WiFi**，或者手机连的就是车机热点。
- 确认手机没有开省电模式把无线调试杀掉。

### 2. 配对失败 / 提示配对码错误
- 配对码有时效，手机端配对弹窗一旦关掉就会失效。
- 重新打开「使用配对码配对设备」，拿到**新的配对码**后立刻在车机端输入。
- 配对过程中手机端弹窗不要切走、不要锁屏。

### 3. 息屏后画面卡住 / 不动了
- 点一下悬浮条上的**灯泡**按钮点亮手机屏，画面一般会立刻恢复。
- 如果频繁出现，检查手机系统是否开启了「锁屏后清理后台」之类的省电策略，把对应进程加入白名单。

### 4. 锁屏后投屏断流
- 本方案**不经过系统录屏（MediaProjection）**，正常息屏（只关背光、不锁屏）不会断流。
- 如果你发现是**手机真的锁屏了**才断流，请在手机上：
  - 关闭自动锁屏，或把锁屏时间调长；
  - 或在车机 App 设置里确认「连接后息屏」处于开启状态（它只关背光、不触发系统锁屏）。

### 5. 画质不够清晰 / 想调帧率
- 进入车机 App 的「设置」，找到「默认画质」和「默认帧率」，按车机屏幕和网络情况调整。
- 网络一般时建议画质适中、帧率 30；网络好时再拉高。

### 6. 手柄没反应
- 确认手柄是在**手机蓝牙**里配对成功，而不是车机蓝牙。
- 部分游戏需要在游戏内的「按键设置」里手动选一下手柄。
- 车机屏幕上的手指点击始终有效，可以先触控进游戏再用手柄。
